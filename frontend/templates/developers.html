Endpoints

GET /api/v1/indicators

Fetch economic indicators for a country.

ParameterTypeRequiredDescription
countrystringYesISO 2-letter code e.g. ZA, NG, KE
indicatorstringNoWorld Bank indicator code
year_fromintegerNoStart year filter
year_tointegerNoEnd year filter
 
curl -X GET "https://your-app.onrender.com/api/v1/indicators?country=ZA&indicator=NY.GDP.MKTP.CD" \
  -H "X-API-Key: es_your_key"
GET /api/v1/compare

Compare an indicator across multiple countries.

ParameterTypeRequiredDescription
countriesstringYesComma-separated codes e.g. ZA,NG,KE
indicatorstringYesWorld Bank indicator code
 
curl -X GET "https://your-app.onrender.com/api/v1/compare?countries=ZA,NG,KE&indicator=FP.CPI.TOTL.ZG" \
  -H "X-API-Key: es_your_key"
